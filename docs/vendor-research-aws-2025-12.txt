# RESEARCH REQUEST: Latest Amazon Web Services (AWS) AI Services and Capabilities
**DATE:** December 2025

## Executive Summary

As of December 2025, Amazon Web Services (AWS) has fundamentally shifted its AI strategy from "generative chat" to **"agentic workflows"** and **"unified data intelligence."** The defining theme of re:Invent 2025 was the transition of AI from passive assistants to active, autonomous teammates capable of executing complex, multi-step tasks.

This shift is anchored by three major pillars:
1.  **The "Agentic" Infrastructure Layer**: The launch of **Amazon Bedrock AgentCore** provides a standardized, enterprise-grade runtime for autonomous agents, moving beyond simple orchestration to handle memory, identity, and long-running execution.
2.  **Next-Generation Foundation Models**: The release of the **Amazon Nova 2** family (Lite, Pro, Omni, and Sonic) introduces "reasoning" models specifically optimized for agentic tasks, offering industry-leading price-performance for automated workflows.
3.  **Unified Development**: The rebranding of SageMaker to **Amazon SageMaker AI** and the General Availability (GA) of **SageMaker Unified Studio** consolidates the fractured landscape of data engineering, analytics, and AI model building into a single "glass pane" interface.

For enterprise customers, the focus has moved to **production reliability** and **cost control**. New capabilities like **Trainium3 UltraServers** and **Lambda Managed Instances** target the high cost of AI compute, while the deprecation of services like **Amazon CodeCatalyst** and **AWS IoT Analytics** signals a consolidation of overlapping tools into more robust, unified platforms.

## Service Map

The AWS AI stack has evolved significantly over the last 12 months. The following map reflects the landscape in December 2025, incorporating renames and new layers for agentic workloads.

*   **AI Platform (Foundation & Orchestration)**
    *   **Amazon Bedrock**: Managed foundation models (Nova, Claude, Llama, etc.).
    *   **Amazon Bedrock AgentCore**: **[NEW]** Low-level infrastructure for agent runtime, memory, and identity.
    *   **Amazon SageMaker AI**: **[RENAMED]** Comprehensive ML platform for model training and deployment.
    *   **Amazon Comprehend / Rekognition**: Specialized AI services (NLP, Vision).

*   **Agent & Copilot Layer**
    *   **Amazon Kiro**: **[NEW]** Agentic IDE for spec-driven software development.
    *   **Amazon Q Developer**: AI coding assistant and transformation agent.
    *   **Amazon Q Business**: Enterprise knowledge assistant.
    *   **Agents for Amazon Bedrock**: Managed high-level agent builder.
    *   **Frontier Agents**: **[NEW]** Pre-built autonomous agents (AWS Security Agent, AWS DevOps Agent).

*   **Data Plane (Unified Intelligence)**
    *   **Amazon SageMaker Unified Studio**: **[NEW]** Integrated environment for Data, Analytics, and AI.
    *   **Amazon SageMaker Lakehouse**: **[NEW]** Unified data access layer (S3, Redshift, Iceberg).
    *   **Amazon OpenSearch Service**: Vector database and search.
    *   **Amazon S3**: Object storage (now with enhanced AI metadata integration).

*   **App Plane**
    *   **AWS Lambda Managed Instances**: **[NEW]** Serverless compute with EC2 flexibility for AI inference.
    *   **AWS Step Functions**: Workflow orchestration.
    *   **Amazon EventBridge**: Event bus for agent triggers.

*   **Security Plane**
    *   **Amazon Bedrock Guardrails**: Content filtering and safety.
    *   **AgentCore Identity**: **[NEW]** Identity management specifically for autonomous agents.
    *   **AWS IAM**: Access control.

## Foundation Models and AI Services

The core of the AWS AI offering remains **Amazon Bedrock**, which has expanded to include the second generation of Amazon's first-party models.

### Amazon Nova 2 Family (Released Dec 2025)
AWS has released the **Amazon Nova 2** series, focusing on "reasoning" capabilities essential for agentic workflows.

*   **Amazon Nova 2 Lite**
    *   **Status**: **GA** [cite: 1]
    *   **Description**: Fast, cost-effective reasoning model designed for everyday agentic tasks and high-throughput automation.
    *   **Capabilities**: Multimodal (Text, Image, Video to Text). Supports "extended thinking" with variable intensity levels.
    *   **Pricing**: ~$0.0003 per 1,000 input tokens; $0.0025 per 1,000 output tokens [cite: 2].
*   **Amazon Nova 2 Pro**
    *   **Status**: **Preview** [cite: 1]
    *   **Description**: High-intelligence model for complex, multi-step reasoning, software migration, and deep analysis.
    *   **Capabilities**: Advanced task decomposition, 1M token context window.
    *   **Pricing**: ~$0.00125 per 1,000 input tokens [cite: 2].
*   **Amazon Nova 2 Omni**
    *   **Status**: **Preview** [cite: 2, 3]
    *   **Description**: "Any-to-any" modality model capable of reasoning across text, audio, video, and image simultaneously.
*   **Amazon Nova 2 Sonic**
    *   **Status**: **GA** [cite: 3, 4]
    *   **Description**: Speech-to-speech model with low latency for real-time conversational AI.

### Amazon Bedrock Updates (Past 6 Months)
*   **Reinforcement Fine-Tuning (RFT)**: **GA**. Allows customers to fine-tune models using reinforcement learning from human feedback (RLHF) directly within Bedrock to align models with specific business logic [cite: 5, 6].
*   **Prompt Caching**: **GA**. Reduces costs by caching frequently used context (e.g., system prompts, documents) [cite: 7].
*   **Guardrails**: Enhanced with new "Policy" controls to deterministically block unauthorized agent actions [cite: 8].

### Pricing Model Overview
Amazon Bedrock continues to use a **On-Demand (Token-based)** and **Provisioned Throughput** model.
*   **On-Demand**: Pay-per-token. Nova 2 Lite is priced aggressively to compete with "Flash" and "Haiku" class models.
*   **Batch Inference**: Offers 50% discount for non-urgent workloads [cite: 9].
*   **Pricing Page**: [AWS Bedrock Pricing](https://aws.amazon.com/bedrock/pricing/)

## Productivity AI and Copilots

AWS has bifurcated its developer tools into "Assistants" (Amazon Q) and "Agentic Environments" (Amazon Kiro).

### Amazon Kiro (Agentic IDE)
*   **Status**: **GA** (Released Nov 17, 2025) [cite: 10, 11]
*   **Description**: A standalone, AI-native IDE (fork of VS Code) designed for **spec-driven development**. Unlike standard copilots that autocomplete code, Kiro generates a full specification, design document, and task list before writing code.
*   **Key Features**:
    *   **Specs & Steering Files**: Users define "steering files" (markdown) to enforce architectural patterns.
    *   **Hooks**: Automated actions triggered by events (e.g., "run tests on save").
    *   **Pricing**: Free Tier (limited), Pro ($19/mo), Pro+ ($39/mo) [cite: 10, 12].
*   **Citation**: [Amazon Kiro General Availability](https://kiro.dev/blog/general-availability/)

### Amazon Q Developer
*   **Status**: **GA**
*   **Description**: The AI assistant integrated into the AWS Console and third-party IDEs.
*   **New Capabilities**:
    *   **Transformation Agents**: Automated upgrades for Java (8 to 17) and Windows-to-Linux migrations [cite: 13, 14].
    *   **Integration**: Now fully integrated into **SageMaker Unified Studio** for data engineering tasks [cite: 15].

## Agentic AI and Automation

This is the most significant area of innovation for AWS in late 2025. AWS now distinguishes between *building* agents (Bedrock Agents) and the *infrastructure* to run them (AgentCore).

### Amazon Bedrock AgentCore
*   **Status**: **GA** (Runtime, Memory, Identity); **Preview** (Policy, Evaluations) [cite: 8, 16]
*   **Description**: A managed infrastructure layer for running autonomous agents. It decouples the agent's logic from the underlying compute and state management.
*   **Components**:
    *   **Runtime**: Serverless execution environment for agents (supports 8+ hour sessions) [cite: 17].
    *   **Memory**: Managed short-term (session) and long-term (episodic) memory [cite: 8].
    *   **Identity**: Manages agent permissions and user delegation [cite: 16].
*   **Pricing**: Consumption-based.
    *   **Runtime**: ~$0.0895 per vCPU-hour (billed per second of active execution) [cite: 18].
    *   **Memory**: ~$0.25 per 1,000 events [cite: 18].
*   **Citation**: [Amazon Bedrock AgentCore](https://aws.amazon.com/bedrock/agentcore/)

### Frontier Agents
*   **Status**: **GA** [cite: 5, 19]
*   **Description**: Pre-built, specialized agents for specific domains.
    *   **AWS Security Agent**: Automates triage and remediation of security findings.
    *   **AWS DevOps Agent**: Diagnoses operational incidents and suggests fixes.
    *   **Kiro Agent**: Acts as a virtual developer peer.

## Data and Analytics AI

AWS has unified its data and AI platforms to solve the "data silo" problem for AI.

### Amazon SageMaker Unified Studio
*   **Status**: **GA** (March 13, 2025) [cite: 15]
*   **Description**: A single integrated development environment (IDE) that combines capabilities from **Amazon EMR**, **AWS Glue**, **Amazon Athena**, **Amazon Redshift**, and **SageMaker AI**.
*   **Key Capability**: Developers can write SQL, build ETL pipelines, train ML models, and deploy GenAI agents from a single interface without switching consoles.
*   **Integration**: Includes **Amazon Q Developer** for generating SQL and PySpark code [cite: 15].

### Amazon SageMaker Lakehouse
*   **Status**: **GA** [cite: 15, 20]
*   **Description**: A unified data access layer based on **Apache Iceberg**. It allows SageMaker AI models to query data residing in S3, Redshift, and third-party sources (Snowflake, etc.) without data movement.

### Vector Search
*   **Amazon OpenSearch Service**: Now supports **GPU-accelerated vector search**, delivering up to 10x faster indexing for RAG workloads [cite: 3].

## Security and Governance

### Amazon Bedrock Guardrails
*   **Status**: **GA**
*   **Update**: Added **Policy** support in AgentCore. This allows admins to define natural language policies (e.g., "Agents cannot access PII in the HR database") that are enforced deterministically at the gateway level, outside the agent's probabilistic logic [cite: 8].

### AgentCore Identity
*   **Status**: **GA** [cite: 16]
*   **Description**: Provides a secure identity layer for agents, allowing them to assume roles and access resources on behalf of users with strict scoping.

## Recommendation Guidance

### Model Hosting
*   **Use Amazon Bedrock** for: Consuming foundation models (Nova, Claude, Llama) via API. It is the default for GenAI applications requiring speed and managed infrastructure.
*   **Use Amazon SageMaker AI** for: Deep customization, full control over training loops, or hosting proprietary models that are not available in Bedrock.

### RAG (Retrieval-Augmented Generation)
*   **Default Pattern**: Use **Amazon Bedrock Knowledge Bases** with **Amazon OpenSearch Serverless** as the vector store.
*   **Why**: This pattern is fully managed, supports hybrid search, and integrates natively with Bedrock Agents.

### Agents vs. Automation
*   **Use Bedrock Agents** when: You need a quick, managed agent for standard tasks (e.g., "Look up order status").
*   **Use Bedrock AgentCore** when: You are building a complex, custom agent platform (e.g., a vertical-specific AI employee) and need control over the runtime, memory persistence, and identity management.
*   **Use Amazon Kiro** when: The task is specifically software development or code generation.

### Anti-Patterns
*   **"Pilot Purgatory"**: Avoid building custom agent frameworks on raw EC2/Lambda. Use **AgentCore** to handle the plumbing.
*   **Tool Sprawl**: Do not use separate tools for data engineering and AI model building. Adopt **SageMaker Unified Studio** to consolidate these workflows.

## Deprecations and Migrations (Past 12 Months)

*   **Amazon CodeCatalyst**:
    *   **Status**: **Deprecated**. Closed to new customers as of **November 7, 2025**.
    *   **Migration Path**: AWS recommends migrating to **GitLab Duo with Amazon Q** or self-managed CI/CD pipelines [cite: 26].
*   **AWS IoT Analytics**:
    *   **Status**: **End of Support** announced for **December 15, 2025**.
    *   **Migration Path**: Migrate to **Amazon Kinesis Data Streams** and **AWS Glue** or **Amazon SageMaker Lakehouse** for data processing [cite: 27, 28].
*   **AWS IoT Events**:
    *   **Status**: **End of Support** announced for **May 20, 2026** (New customers blocked May 2025).
    *   **Migration Path**: Use **Amazon CloudWatch** or custom event processing via **AWS Lambda** [cite: 27].
*   **Amazon SageMaker Studio Classic**:
    *   **Status**: **End of Maintenance** as of **December 31, 2024**.
    *   **Migration Path**: Migrate to the new **Amazon SageMaker Studio** (part of Unified Studio) [cite: 29].
